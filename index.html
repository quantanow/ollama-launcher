How it works

Three steps to launch

01
Pick an agent

Choose from claude, codex, hermes, openclaw, or opencode. Fuzzy-searchable.

02
Pick a model

Search across 100 top models from ollama.com by name, capability tag (vision, thinking, cloud), or pull count.

03
Pick a variant

Select the exact size and quant — 3b, 8b, 70b, q4_K_M, :latest. Size and context window shown inline.

Features

Everything in one command

⚡
fzf-powered fuzzy search

Instantly filter 100 models by name, tag, or variant. Falls back to a numbered menu if fzf isn't installed.

☁
Cloud model filtering

Type "cloud" in the model picker to surface all models with a :cloud variant. Use --list-models --cloud to print them directly.

📦
Fully offline

All 100 models and 332+ variants are embedded in the script. No network calls at runtime — works anywhere ollama works.

🔄
Easy model switching

Re-run ollama-launch any time to jump to a different model or variant. No memorizing names or copy-pasting from the website.

🖥
Single bash script

One self-contained file. No Node runtime, no dependencies beyond ollama itself. Works on macOS and Linux with bash 3.2+.

🔍
Rich metadata inline

Pull counts, capability tags, model size, and context window length shown directly in the picker — no tab-switching required.

Usage

CLI flags

Flag Description
(no args) Open the interactive picker and launch
--list-agents Print all available agent names and exit
--list-models Print all 100 model names and exit
--list-models --cloud Print only models that have a :cloud variant and exit
--version / -v Print version and exit
--help / -h Show usage information and exit
